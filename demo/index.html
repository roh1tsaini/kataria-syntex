Open the web app

First run

Three steps each, and nothing to configure. Your sign-in is a QR code shown on the web app — no password is ever typed on a phone.

01 — ANDROID

Phone or tablet

  1. Tap Download APK above.
  2. Android will ask to allow installs from this source — allow it once.
  3. Open the file, install, then sign in by scanning the QR on the web login screen.

Android may show a Play Protect prompt for a non-Play build. Choose Install anyway — the APK is release-signed and every future update carries the same signature.

02 — DESKTOP

Windows, macOS, Linux

  1. Windows: run the installer, then More info → Run anyway at the SmartScreen prompt.
  2. macOS: open the .dmg, drag the app across, then right-click → Open the first time.
  3. Linux: chmod +x the AppImage, then run it. No install needed.

The desktop builds aren't code-signed with a paid certificate yet, which is why the OS asks once. After the first launch it opens normally.

03 — BROWSER

Nothing to install

  1. Open the web app and sign in with your phone number.
  2. Optional: use Install in the address bar to pin it as an app.
  3. On a phone, use Add to Home Screen for the same result.

Best for a machine you don't control — a client's laptop, a borrowed cabin. Nothing is left behind but a browser cache.
