# Smooth-motion rollout — morph grammar repo-wide

Chosen feels: **Calm (0.38s critically-damped spring)** for apps/app + apps/android · **Cinematic (0.6s, soft settle)** for apps/web. Per your word: motion ships full-strength everywhere — the existing reduced-motion kill-switches (OS opt-in only) stay as-is, nothing gets watered down, no spam/jumps.

**Key technical fact:** motion/react's `layoutId` engine animates size changes via transforms (scale/position corrections), not raw width/height tweens — so the morph pattern satisfies design.md §5 rule 1 unchanged. The compare page's width/height approach was just a demo.
